# Audiobook Speed Calculator

Free browser tool: enter an audiobook’s length, pick a playback speed (1×–3×+), and instantly see real listening time and hours saved.

**Live site:** https://audiobookspeedcalculator.net/

- No signup
- No audio upload
- All math runs locally in your browser

## Use case

For listeners who speed up Audible, Libby, Spotify, Apple Books, Storytel, and similar apps, and want to know how long a book will actually take at their preferred speed.

## Stack

Static HTML/CSS/JS on [Vercel](https://vercel.com/), custom domain via Cloudflare DNS.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
